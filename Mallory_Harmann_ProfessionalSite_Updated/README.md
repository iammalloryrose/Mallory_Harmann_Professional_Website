# Mallory Harmann | GIS & Geospatial Portfolio

Professional portfolio website highlighting GIS, WebGIS, geospatial programming, and environmental research.

## Website sections
- WebGIS and interactive mapping projects
- GIS programming and ArcPy automation
- Environmental research and presentations
- Technical skills and education
- Professional contact links

## Featured project repositories
- [WebGIS & JavaScript Portfolio](https://github.com/iammalloryrose/Mallory_Harmann_Webgis_Portfolio)
- [GIS Programming & ArcGIS Pro Portfolio](https://github.com/iammalloryrose/Mallory_Harmann_GIS_Programming)

## Local preview
Open `index.html` in a browser. The site uses local CSS and image assets. Google Fonts are loaded from Google Fonts when an internet connection is available; system sans-serif fallbacks are provided.

## Publishing
This site is structured for GitHub Pages from the repository root. In the repository settings, configure Pages to deploy from the `main` branch and `/ (root)` if Pages is not already enabled.

## Notes
The featured GIS project cards link to the source project folders in the two public repositories. The site does not duplicate the full source repositories. Existing research detail pages and poster images have been retained.
